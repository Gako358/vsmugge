#+title: vsmugge — the mugge chat in a VS Code sidebar

A frontend for the always-on mugge chat client, the VS Code sibling of
[[https://github.com/gako358/mugge.el][mugge.el]]. It is *not* a second client: the background service owns the
one connection to the server (auth, reconnect, notifications), and this
extension attaches to it locally.

Two ways to attach, both against the same live session:

- *Chat sidebar* (the Mugge icon in the activity bar) — a proper chat
  view: message blocks per sender, online roster, typing line, code
  blocks, and a composer that sends on Enter. It talks to the client's
  companion socket at =$XDG_RUNTIME_DIR/mugge-ipc.sock=, which serves
  JSON events and accepts plain chat lines.
- *Terminal attach* (=Mugge: Attach Terminal=) — =dtach -a= against
  =$XDG_RUNTIME_DIR/mugge.sock= in an integrated terminal, rendering the
  full raw-mode TUI. Use it for what the sidebar deliberately leaves out:
  voice, file transfer, assist consent and tab completion.

The sidebar needs a client build that carries the companion socket
(=Ipc.scala=); against an older client it just shows "waiting for the
mugge client…". Set =MUGGE_NO_IPC=1= on the service to turn the socket
off entirely.

* Commands

| Command                        | Action                                             |
|--------------------------------+----------------------------------------------------|
| =Mugge: Open Chat=             | Focus the sidebar chat                             |
| =Mugge: Reconnect Chat Socket= | Drop and re-open the companion socket              |
| =Mugge: Attach Terminal=       | dtach attach in a terminal (offers to start it)    |
| =Mugge: Detach=                | Dispose the local attach terminal                  |
| =Mugge: Service Status=        | Show =systemctl --user status mugge-chat=          |
| =Mugge: Start Service=         | =systemctl --user start mugge-chat=                |
| =Mugge: Stop Service=          | =systemctl --user stop mugge-chat= (prompts first) |

* Settings

| Setting                | Default        | Meaning                                         |
|------------------------+----------------+-------------------------------------------------|
| =mugge.ipcSocketPath=  | =""=           | Empty derives =$XDG_RUNTIME_DIR/mugge-ipc.sock= |
| =mugge.socketPath=     | =""=           | Empty derives =$XDG_RUNTIME_DIR/mugge.sock=     |
| =mugge.dtachProgram=   | ="dtach"=      | dtach binary name or path                       |
| =mugge.serviceUnit=    | ="mugge-chat"= | systemd user unit name                          |
| =mugge.startTimeout=   | =10=           | Seconds to wait for the socket after start      |

* Building

#+begin_src sh
npm install
npm run compile
#+end_src

Or with nix:

#+begin_src sh
nix build
#+end_src

The flake package installs into =share/vscode/extensions/gako358.mugge=, so it
can be listed directly in home-manager's =programs.vscode= extensions:

#+begin_src nix
programs.vscode.profiles.default.extensions = [
  inputs.vsmugge.packages.${pkgs.system}.default
];
#+end_src

=dtach= must be on the PATH VS Code sees (or set =mugge.dtachProgram= to an
absolute path) for the terminal attach; the sidebar needs no external
program.
